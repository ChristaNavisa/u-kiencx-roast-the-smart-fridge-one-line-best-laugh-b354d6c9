One line roasting the robot vacuum that shares the house: it mapped the dog as a "soft obstacle" and now avoids him with more respect than it shows its owner.

The roast works because the gadget convicts itself: "soft obstacle" is mapping vocabulary, and the turn at the end — more respect for the dog than for the owner — is the sting, not an observation.
